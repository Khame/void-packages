Khame XBPS repository

Signed x86_64 packages for Void Linux, built for runit (no systemd).

Packages

  • asusctl — ASUS ROG control daemon, CLI tools and KDE Plasma widget. Documentation: Khame/asusctl-void-linux

Usage

sudo sh -c 'echo "repository=https://khame.github.io/void-packages/" > /etc/xbps.d/10-khame.conf'
sudo xbps-install -S      # answer Y to import the repository key
sudo xbps-install asusctl

Contact

Questions and build reports: khame.dev@protonmail.com

Signing key

Packages are RSA-signed. The key is embedded in the repository index and imported by xbps automatically; Khame-void-repo.pub is published for manual verification. Unsigned installation is not supported.
